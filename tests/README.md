# M1 の要件とテスト

合成ログの再生テストは `cargo test --test replay` で実行します。すべての PR では `bash .github/scripts/verify.sh` で実行します。

## 再生ケース

`tests/replay/<ケース名>/` に `ViveTrackerServer_YYYYMMDD.txt` を 1 つ以上と、`expect.toml` を置きます。ログはファイル名の日付順、各ファイル内は行順に流します。ケース名のハイフンをアンダースコアにした名前のテストを `tests/replay.rs` に追加します。

| ケース | 確認すること |
|---|---|
| `synthetic-r1-second-host-command` | ホストへの 2 度目の命令の後に Wi-Fi の問い合わせが続く。R1 をホストについて 1 回検出する |
| `synthetic-normal-start` | ホストからクライアントへ Wi-Fi 情報が渡り、地図の同期と位置合わせが終わる。検出は 0 回 |
| `synthetic-utf16` | ふつうの開始のケースを UTF-16LE（BOM つき、CRLF）にしたもの。行数と検出結果が元のケースと一致する |

M1-2 では 3 ケースの解読と先頭の解析を確かめます。検出を比較するテストは M1-6 で有効にします。実物のログを追加する場合は、L-1 の匿名化を通したものを使います。

## 要件との対応

要件と受け入れの基準は [PRD の 5 章](../docs/product/PRD.md#5-m1-見張り役)、テストの順序は [実装計画](../docs/design/implementation-plan.md) に従います。

| 要件・受け入れの基準 | 確かめ方 | テストの場所 |
|---|---|---|
| W-1 UTF-16 のログを追記分だけ読み、0 時に切り替える | 単体テスト（解読、ヘッダー、行の種類、追記と切り替え）、合成ログの再生、オーナーの実機（VIVE Hub が書き込んでいる間に読めるか） | M1-1、M1-3、M1-4。`tests/replay.rs` の `synthetic_utf16`。実機は設計 14 章の U-13 |
| W-2 トラッカーごとの状態と PC 側の Wi-Fi 情報を保つ | 単体テストで状態遷移表の各行を確かめる | M1-5 |
| W-3 Wi-Fi 情報なしを検出し、対象の電源入れ直しを案内する | 単体テストで R1 と案内の対象・文言を確かめる。合成ログと匿名化ログの再生。オーナーの実機で電源入れ直しの効果を確認 | M1-6、M1-7、M1-13。`tests/replay.rs` の `synthetic_r1_second_host_command_detections` と `synthetic_normal_start_detections`（M1-6 で有効化）。実機は設計 14 章 |
| W-4 地図同期の遅れ、ホストの位置合わせ、操作と関係のない切断を検出し案内する | 単体テストと合成ログの再生で R2、R3、R4 の条件と境目を確かめる | M1-6、M1-7 |
| W-5 デスクトップと SteamVR に案内し、繰り返しを抑える | 単体テストで配信、間隔とまとめを確かめる。オーナーの実機で両方の表示を確認 | M1-7、M1-10、M1-11、M1-12 |
| W-6 日ごとの集計をファイルに残す | 単体テストと合成ログの再生で、日付の切り替えと集計値、ファイル出力を確かめる | M1-8、M1-9 |
| W-7 実機に命令を送らない | 依存と入出力をレビューし、ログの読み取り専用オープンを単体テストで確かめる | 全項目のレビュー、M1-4・M1-9 のログ読み取り |
| W-8 保存したログを時刻順に流して検出を確かめる | 比較の単体テストと、合成・匿名化ログの再生テストを CI で実行する | `src/replay.rs` の単体テスト、`tests/replay.rs` の 3 ケース、M1-6、M1-13 |
| W-9 ログの場所、台数、シリアル番号を固定しない | 単体テストで設定と自動検出、合成ログで台数と識別子を変えて確かめる | M1-5、M1-9 |
| 受け入れ：2026-11-22〜27 のログで W-3 が 4 回だけ | 匿名化ログの再生で 11/26 01:43、11/27 22:53・22:56・22:59 の検出だけがあることを確かめる | M1-13。PM が匿名化したログを追加した後に `tests/replay/hub-2026-11-22-27/` を使用 |
| 受け入れ：VR の動作を重くしない | オーナーの実機で VIVE Hub と SteamVR を動かし、OpenUT の使用前後のフレーム時間と、使用中の CPU・メモリを確認 | M1-9〜M1-12。実機は設計 12 章 |
| 受け入れ：想定と違う行があっても読み続ける | 単体テストで乱れたバイト列、知らない行、壊れた数値と、その次の行の扱いを確かめる | M1-1、M1-3 |
