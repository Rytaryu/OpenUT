# 調査の記録（2026-11-27）

オーナーの PC の VIVE Hub のログ（2026-11-22〜27）を読んだ結果と、先行事例。シリアル番号などの個人の情報は載せていない。

## 構成

VIVE Hub 2.5.6、Ultimate Tracker ランタイム 1.2.5（公開版の最新）、トラッカーのファームウェア 1.0.999.178、ドングル 1 台にトラッカー 3 台、HMD は Meta Quest 3。

## 始まらない問題（PC 側の不具合）

- 6 日間で、ホスト役の開始は 24 回。うち 4 回（11/26 01:43、11/27 22:53・22:56・22:59）で、後から来たトラッカーが位置を出せないまま止まった。
- 4 回とも経過は同じ。`switch to HOST mode` が 2 度出る。2 度目のあとに `Query wifi` と `Got host wifi info` が出ない。以後 `Wifi info is not yet available.` が約 0.55 秒おきに続き、後から来たトラッカーに `Assign wifi info` が一度も出ない。
- 2 度目の命令は、4 回とも、次のトラッカーが登録される 0.3〜1.3 秒前に出ている。なぜ出るかは未特定。
- 不具合の前に Wi-Fi 情報をもらったトラッカーは、そのまま動く。
- ドングルのリセットと再ペアリングでは直らない（11/27 は 3 回やって 3 回とも再発）。
- ホストが交代すると、PC は Wi-Fi 情報を取り直す（11/23 22:44・23:30、11/26 01:41）。不具合の状態でこの交代を試した記録は、まだない。

仕組み: トラッカーは 1 台がホストになって Wi-Fi の親機を立て、残りはそこにつないで地図をもらう。クライアントは接続先を PC に尋ね、PC はホストから聞いておいた SSID・パスワード・周波数を答える。

## 途切れる問題（トラッカー側）

- 「追跡中 → 喪失」の切り替わりは 6 日で 234 回。直前 12 秒以内に PC からそのトラッカーへ命令が出ていたのは 9 回だけ。PC 側のソフトが起こしたものではない。
- 1 分を超える喪失は 19 回。開始直後が多いが、使用中にもある。11/27 00:18 には、腰と推定される 1 台が、座った姿勢のまま約 7 分失っている。
- ホストの開始 24 回のうち 11 回で、開始から 20 秒以内に喪失の通知が出ている。
- ホストが位置を出すまで 5.5〜322 秒（11/23〜27）。クライアントが地図を受け取るまで 1〜12 秒の回と 40〜550 秒の回がある。
- 無線の取りこぼしは中央値で 0.1〜0.5%。操作と関係のない切断は 1 日 1〜3 回。主因ではない。
- 理由（部屋、照明、装着中のカメラの遮り、地図の質、トラッカー内のソフト）は、PC 側のログでは分からない。

## 次に確かめること

- **トラッカー内のログ。** VIVE Hub に同梱のログ収集ツール（`ViveUTUpdateManager\UTCollectLog`）が、USB でつないだトラッカーからログの束を取り出す。喪失の時刻の前後を読めば、理由が分かる見込みがある。
- **ホストの入れ直しで不具合が直るか。**
- **座るときの腰のトラッカーの位置と向き。**

## 先行事例

| 実装 | 何をするか | Windows |
|---|---|---|
| [pyvut](https://github.com/rocketmark/pyvut) | ドングル経由で最大 5 台の姿勢を取る Python ライブラリ。ホスト役の割り当てと Wi-Fi 情報の受け渡しを自前で行う。ライセンスの表示なし | Linux 向け |
| [vive_ultimate_tracker_re](https://github.com/shinyquagsire23/vive_ultimate_tracker_re) | USB HID とドングルの通信の解析。ライセンスの表示なし | — |
| [vive-ultimate-linux](https://github.com/uzugu/vive-ultimate-linux) | pyvut → 姿勢デーモン → OpenVR ドライバー。Windows 版 VIVE Hub の解析メモつき | ドライバーはビルドできる。実機では未確認 |
| [utk-steamvr](https://github.com/xkeyC/utk-steamvr) | HTC の Linux SDK を使う SteamVR ドライバーと、VR 内での較正 | Linux のみ |
| [Vive_Ultimate_tracker_Wifi_Solution](https://github.com/zihaodream/Vive_Ultimate_tracker_Wifi_Solution) | ドングルを使わず、5GHz ルーター経由で SteamVR に渡す。初回設定に ADB が要る | 対応 |
| [VIVE Ultimate Tracker Linux SDK](https://github.com/ViveRoboticsSoftware/vive-ultimate-tracker-sdk) | HTC 公式の姿勢 SDK。VIVE Product EULA | Linux のみ |

解析メモから分かっているトラッカーの中身: Android 7.1.2（userdebug、arm64）。地図は ORB-SLAM 風の構造。ファームウェア 1.0.999.178 では、adb は `/sdcard` の一覧とログの束の取り出し以外を拒否する。
